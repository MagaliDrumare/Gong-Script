# Demo Script — Finance Analyst Agent & Store-Level Analysis

**Source:** Bosselman | OneStream AI Agents, 28 Jul 2026 · Presenter: Logan Shallenberger, Dir, AI Solution Consult. · Segment: ~17:49–45:07 (~27 min)
**Audience on source call:** Bosselman (multi-location retail/hospitality) + Holland Parker — adapt store/district/regional hierarchy, board-report brevity, and reconciliation interest to your prospect.

## At a glance
- **What you demo:** Finance Analyst live — **Finance Analyst Cube View**, automated variance drill with materiality thresholds, **NAE Equipment Monthly Variance Report**, HTML/presentation output for board-ready summaries, and store-level trend analysis for a multi-location operator.
- **Core value message:** Agents automate the analysis legwork — variance drill, store trends, month-end narrative — so accountants analyze locations and the CFO gets shareholder-ready insight without rebuilding decks for a week at close.
- **Demo environment needed:** OneStream demo tenant with Finance Analyst; sample cube with store/district/regional dimensions; variance report configured (NAE Equipment example); HTML presentation deck output enabled.

## Argumentation structure
1. **Pain** — Accountants manually drilling each location for swings; CFO spends days on month-end shareholder email and board materials; finance team once spent a **week** building 30–35 cost-center review decks every month.
2. **Status quo cost** — Excel-heavy forecasting; AI outputs default to 20–30 page reports when board wants **two pages**; reconciliations still manual despite living in OneStream.
3. **Capability** — Finance Analyst pulls subsequent cube slices automatically; navigates until materiality threshold met; generates HTML reports and configurable PowerPoint-style decks — management-facing or operations-deep.
4. **Proof** — Live **Finance Analyst Cube View**; **NAE Equipment Monthly Variance Report**; agent explains variance by drilling cube hierarchy; store trend classification over 3–6 months by region.
5. **Differentiator** — Grounded in governed cube data at store level (no transactional history required for core use cases); instruct AI for brevity — "be brief, be blunt, be gone" — not default 30-page outputs.
6. **Payoff** — Rich gets month-end email support; Misty's accountants catch location swings before close; entire cost-center deck week **given back** via automated AI-built presentations.

## Key messages to land
- Variance drill is **automatic and materiality-aware** — agent navigates cube until explanation found or bottom reached.
- **Store / district / regional** analysis without transactional history — cube-level detail is sufficient for trend and variance use cases.
- **Month-end shareholder email** and **location monitoring** are direct Bosselman-fit use cases.
- Cost-center deck week → **automated AI-built decks** — configurable management vs. operations depth.
- Board brevity: instruct agent for **two-page summary** — not default long AI reports.
- Deeper detail may require **transactional history** — flag as expansion path, not blocker for core demo.
- Reconciliations: discussed as customer priority — **not live-demoed on this call**; schedule follow-up.
